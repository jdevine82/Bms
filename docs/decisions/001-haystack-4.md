# Haystack 4.0.0 compatibility

Date: 1 Nov 2026. Status: decided.

The data model follows Project Haystack 4, pinned to haystack-defs v4.0.0 (ph and phIoT), not the newer Xeto format. A read-only Haystack HTTP API (about, ops, formats, read, nav, hisRead, watch) with SCRAM login is offered, off by default, with no pointWrite in v1.

Spec: 5.2, 5.12, Appendix A
