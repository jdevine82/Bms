# Graphics: symbols from Equinor's library, graphics in the setup

Date: 6 Nov 2026. Status: decided.

The shipped symbol library uses Equinor's engineering-symbols (MIT licence) for the symbols it covers (pumps, fans, valves, dampers, tanks, sensors, coils, filters), recoloured by the BMS for states and the dark theme; the symbols it lacks (lights, doors, meters, compressors and other HVAC gaps) are drawn for this project in the same line style. Graphics are part of the site setup (`graphics` in the config file), checked, exported, backed up and edited by admins. Milestone 9 is in two parts: 9A model, library, rendering and tabs; 9B the editor, custom symbols and SVG import.

Spec: main spec 6.4, 6.5; docs/specs/m9-graphics.md
